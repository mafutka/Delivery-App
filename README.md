🍔 Food Delivery App

A modern food ordering web application inspired by services like Glovo. Users can browse products, add items to a cart, and place orders with a simple and intuitive interface.

✨ Features
🛒 Add/remove items from cart
📦 Create and submit orders
✅ Form validation (name, email, phone, address)
⚡ Fast and responsive UI
🔄 Real-time order submission
🧾 Error handling with user-friendly messages

🛠️ Tech Stack
Frontend: React / Next.js
Language: TypeScript
State Management: React Hooks
Validation: Yup
API: Custom backend API
Styling: CSS Modules
